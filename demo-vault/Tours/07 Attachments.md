# Work with local attachments

## A local illustration

![[Attachments/Station.svg|640]]

The image is an original drawing made for this fictional station. Attachments remain local files. Paste/drop an image or use Attach files in the note menu to copy your own example into the vault. Configure an attachment destination in Settings → Files.

## A small PDF

![[Attachments/Field card.pdf]]

PDF display depends on the desktop platform. If it cannot display inline, reveal the file using its attachment heading.

## Audio and video

![[Attachments/Station chime.wav]]

![[Attachments/Status loop.webm]]

The short sound and silent animation were generated for this demo. Playback depends on platform codecs. Media controls are local, and supported resources allow seeking. Unknown file types remain attachment cards that can be revealed in the file manager.
