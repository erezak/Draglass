# Organize ordinary files

Use Cmd/Ctrl+Shift+P to open the command palette. Commands can be pinned and recently used commands are easier to revisit. Cmd/Ctrl+P opens the note switcher. The explorer supports folders, context menus and drag-to-move review.

Try these exercises with [[Practice/Move this note]]:

- Create a folder, then move or rename the practice note.
- Review the proposed file/link changes. Choose whether to update links.
- Verify that links from [[Practice/Links to the movable note]] were updated.
- Delete the practice note with confirmation, then use Browse Draglass trash to restore it.

The default trash stays inside the vault; system trash is available in Settings. Restoring does not overwrite existing files. Note tabs preserve editor state, and edits autosave. If a save fails, the editor retains your draft and the close guard gives you a chance to keep it.

## Open files outside a vault

Use Open file to select a Markdown or Excalidraw file outside the demo. It opens in a detached window with an explicit label and distinct appearance. Detached Markdown starts in Live Preview. Its relative links resolve beside that file. This exercise needs a file outside the vault; it does not pretend that a bundled example is detached.
