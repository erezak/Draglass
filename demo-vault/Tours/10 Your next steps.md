# Make the workspace yours

The examples are yours to edit. Reopening **Open demo vault** returns to this editable edition. If a future release changes the bundled examples, it opens a fresh edition while retaining earlier demo folders and their edits in application data. Reveal a note in the file manager to find the current edition.

Open your own folder with **Open vault** whenever you are ready. If you quit while your folder is active, Draglass reopens that folder. If you quit while this demo is active, it reopens the demo with its saved tabs and layout.

Use the command palette to return to the demo at any time. Nothing from the demo is merged into your own folder.

The app is an editor for ordinary files. Some capabilities need an actual exercise: AI requires a configured connection; external refresh requires a second editor; OS file associations require an installed desktop build. The tour explains these without fabricating results.

Return to [[Welcome]] or start exploring [[Systems/Beacon service]].

Opening the demo shows progress. If it cannot open, an error dialog explains the failure and your current vault stays open.
