# Daily Notes

A daily note is a time-stamped entry point for capturing whatever is on your mind today — tasks, observations, meeting notes, ideas. Over time the collection becomes a personal timeline woven into the rest of your vault through [[Wikilinks]].

## A typical daily note

```markdown
# 2026-02-07

## Tasks
- [ ] Read chapter 3 of [[Philosophy]] textbook
- [ ] Review meeting notes on [[Technology]] strategy
- [x] Push bugfix for the search feature

## Notes
Interesting connection between Socrates' method and
modern [[Critical Thinking]] frameworks. Worth expanding
into [[Ancient Greece]] note.

## Reflections
The daily review habit is paying off — found three old
ideas that link to today's work via [[Backlinks]].
```

Because Draglass scans every note for checkboxes, the `- [ ]` items above would appear in the [[Tasks and Checklists|Tasks panel]] on the right sidebar. Completed items (`[x]`) are hidden from the panel.

## Linking from daily notes

The power of a daily note is that it links outward:

- Reference projects, people, and concepts with [[Wikilinks]].
- Those notes gain [[Backlinks]] pointing back to the daily note, creating a timeline view for each topic.
- Open [[Graph View]] and a daily note appears as a small hub connecting the ideas you touched that day.

## Building a review habit

1. **Capture** — write everything in today's note without worrying about organization.
2. **Process** — at the end of the day, move permanent insights into topic notes and add [[Wikilinks]].
3. **Review** — weekly or monthly, skim recent daily notes. Check which [[Tasks and Checklists|tasks]] are still open. Follow [[Backlinks]] to see what referenced what.
4. **Search** — use [[Searching Your Vault|Global Search]] (**Cmd/Ctrl + Shift + F**) to find patterns across daily notes.

> [!tip] Quick start
> Use the Quick Switcher (**Cmd/Ctrl + P**) and type today's date to jump straight to your daily note.

## Variations

Some people prefer weekly notes, monthly reviews, or quarterly planning notes. The pattern is the same: a time-stamped page that links outward into the rest of the vault.
