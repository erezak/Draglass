# Live Preview playground

This note stays editable while it looks like a rendered document.

Click into **bold**, *italic*, ~~strikethrough~~, or `inline code` to reveal the Markdown markers. Move the cursor away to hide them again.

## Lists and tasks

- A regular list item
- Another item with **emphasis**
- [ ] Click this checkbox
- [x] This task is already complete

> A quote is still ordinary Markdown, even when it has a styled border.

## Connections

Click [[Welcome|the welcome note]] to edit its link. Cmd/Ctrl-click to follow it.

## An editable table

Click a cell and type. Each edit updates the Markdown and autosaves.

| Feature | State |
| --- | --- |
| Live Preview | Ready |
| Tables | Editable |
| Tasks | Interactive |

Use Tab to move between cells. The **Edit table Markdown** button reveals the entire table source. The top **Source** button switches the whole editor to source mode.
