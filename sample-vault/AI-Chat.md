# Think with your notes

Draglass can discuss this note, explain an idea, or compare it with another note.

## Try it

1. Open **Settings** and select a provider. Use an installed, signed-in Copilot, Codex or OpenCode CLI, or configure an API model and gateway URL.
2. Ask the chat: “What are the central ideas in this note?”
3. Type `@`, choose **Connected thinking.md**, then ask how the two notes relate.
4. Edit a sentence and send immediately. Chat includes the current editor text, even before autosave finishes.

The context chips show which notes will be sent. Conversations are saved separately for each note. Use **New chat** to start again.
