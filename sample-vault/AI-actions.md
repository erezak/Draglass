# Try reviewed AI changes

Open Note chat and select **Propose changes**. Choose a configured provider, then try:

> Improve this note's wording, add a short checklist, and propose a new note at Summaries/AI review.md with the key ideas. Keep the examples below.

For multiple notes, type `@` and select another note to include it in the context.

## Review first

- Generating a proposal does not change your files.
- Review the diff or the complete proposed text.
- Accept or reject each note independently.
- Undo an accepted change while the note still matches the applied text.
- Undoing a newly created note moves it to Draglass trash.

If a note changes after a proposal was generated, ask for a fresh proposal.
