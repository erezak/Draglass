# Organize your thinking

Press **Cmd/Ctrl+Shift+P** and search for Rename, Move, Create folder or Browse trash. Star an action to pin it.

## Try a rename

This note links to [[Welcome]]. Open Welcome, press F2 and give it a new name. The link here updates, while this example stays literal:

```md
[[Welcome]]
```

## Try a folder

Create a folder from the explorer's folder icon. Right-click a note to move it, or drag it onto the folder. Review the affected files and links before applying.

## Restore a deleted note

Move a note to trash from its menu. Open Browse Draglass trash from the palette to restore its original path. Existing files are preserved.

Settings now includes editor, file/link and appearance preferences. Try line numbers, a different font size, or right-to-left text direction. The AI providers page keeps your existing CLI and gateway connections.
