HTTP headers

Custom headers override defaults, including Authorization. Leave a saved value blank to retain it. Remove a row to delete that header.

Shared HTTP proxy

Applies to all API connections and CLI processes launched by Draglass.

Enter an HTTP or HTTPS proxy URL. The same proxy handles HTTP and HTTPS destinations. Bypass uses comma-separated hosts or domains. CLI providers receive HTTP_PROXY, HTTPS_PROXY and NO_PROXY; their own configuration may also affect routing.

Core plugins

Bundled features you can turn on and off. Changes take effect immediately for this vault.

Disabling the plugin hides its workspace and commands. Its Markdown notes are preserved.

Daily Briefing

Collect evidence through a compact clipboard exchange. Imports apply automatically with 10-minute Undo. Local edits win conflicts.

Working days

AI searches and reads relevant notes through bounded tools. Without a connection, structured import still works. Configure providers in AI settings. Prompts contain changed task and decision fields only; acknowledgments track requested memory updates. External task records are never changed by the prompt.

Calendar

Dots reflect current words in dated Markdown notes: 250 words per dot, up to five. They do not reconstruct edit history.
