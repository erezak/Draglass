# Sample data

Examples use the fictional Lumen field station: Mara Chen, Noam Levi, Imani Okafor and Alex Rivera, the Lumen Research organization, and its invented systems, sources and activities. Dates, evidence and identifiers demonstrate behavior rather than report real events. The illustrated portraits, station map, field card, readings, chime and status animation are synthetic sample media.

Use reserved example domains for sample links and email addresses. Never copy real correspondence, employee identifiers, private service addresses, credentials or local home paths into examples, tests or prompts. Provider adapters may retain official service endpoints and documentation links. Owner attribution, public project links and third-party licenses remain intact.

Run `pnpm run check:demo` to validate the demo network, evidence quotations, coverage and sample endpoints. The sample check also inspects decoded standalone and inline drawing scenes, including compressed payloads. This check is a guard against common mistakes; fictional names and narrative still require editorial review.

The neutral [knowledge ontology](KNOWLEDGE_ONTOLOGY.md) documents the entity vocabulary and template fields. Application-specific data belongs in the user's vault, not in bundled examples.
