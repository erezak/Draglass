# Graph View

The Graph View visualizes the connections between your notes, showing how ideas relate to each other.

## What Is the Graph View?

Graph View displays:
- **Nodes**: Each note is a node
- **Edges**: [[Wikilinks]] create connections between nodes
- **Clusters**: Related notes naturally group together

## Opening Graph View

Access it via:
- Command Palette: "Show Graph"
- Keyboard shortcut: Check your settings
- Toolbar button

## Understanding the Graph

The graph reveals patterns in your thinking:

- **Central nodes**: Frequently linked notes like [[Welcome to Draglass]]
- **Clusters**: Related topics like [[Philosophy]], [[Science]], [[Technology]]
- **Orphans**: Unconnected notes that might need links
- **Bridges**: Notes connecting different areas

## Using the Graph

The graph helps you:

1. **Find connections**: Discover unexpected relationships
2. **Identify gaps**: See where you could add links
3. **Navigate**: Click nodes to open notes
4. **Understand structure**: Visualize your knowledge architecture

## Graph Patterns

Common patterns that emerge:

- **Star pattern**: Hub note with many links (see [[Organization Strategies]])
- **Chain pattern**: Linear progression of ideas
- **Web pattern**: Highly interconnected area
- **Islands**: Separate clusters that could be bridged

## Related Features

- [[Wikilinks]] - Create the connections
- [[Backlinks]] - See individual connections
- [[Search]] - Find specific content
- [[Tags]] - Alternative grouping

The graph is particularly powerful when combined with [[Daily Notes]] and [[Workflow]] practices.
