# Creating Notes

Learn how to create and manage notes in Draglass.

## Methods to Create Notes

### 1. Command Palette
Press **Cmd/Ctrl + Shift + P** and select "New Note". See [[Quick Start Guide]] for more shortcuts.

### 2. Wikilinks
The easiest way! Just type `[[New Note Name]]` in any note. When you click the link, Draglass will create the note if it doesn't exist. This is explained in [[Wikilinks]].

### 3. File Tree
Right-click in the file tree sidebar to create notes in specific folders.

## Naming Conventions

Good note names make your vault easier to navigate:

- Be descriptive: "Project Meeting Notes 2024" vs "Notes"
- Use consistent capitalization
- Avoid special characters that might cause issues
- See [[Organization Strategies]] for more tips

## File Format

All notes are stored as `.md` (Markdown) files. This means:
- Your notes are plain text
- They're portable and future-proof
- You can edit them in any text editor
- Learn more in [[Markdown Syntax]]
