# Quick Start Guide

This guide will help you get started with Draglass quickly.

## Basic Navigation

- Use **Cmd/Ctrl + P** to open the Quick Switcher
- Use **Cmd/Ctrl + Shift + P** to open the Command Palette
- Click on files in the left sidebar to open them

## Creating Notes

There are several ways to [[Creating Notes]]:

1. Use the "New Note" command from the Command Palette
2. Click the "+" button in the toolbar
3. Create a wikilink to a non-existent note and click it

## Using Wikilinks

[[Wikilinks]] are the heart of Draglass. Simply wrap a note name in double brackets:

```markdown
[[Another Note]]
```

This creates a bidirectional link between notes. Learn more at [[Backlinks]].
