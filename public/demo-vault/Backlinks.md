# Backlinks

Backlinks show you which notes link to the current note. This creates a bidirectional knowledge graph.

## Understanding Backlinks

When you create a [[Wikilinks|wikilink]] to a note, that note automatically gains a backlink. This means:

- You can see what references a note without searching
- Related ideas naturally cluster together
- Your knowledge base becomes more discoverable

## Using Backlinks

Backlinks appear in the right sidebar (when enabled). They help you:

1. **Discover connections**: Find related notes you forgot about
2. **Verify context**: See how a concept is used elsewhere
3. **Navigate**: Jump to notes that reference this one
4. **Build MOCs**: Create Maps of Content using backlink patterns

## Backlinks in Practice

For example:
- This note about [[Philosophy]] might be referenced by [[Ancient Greece]] and [[Ethics]]
- Your [[Daily Notes]] might all reference your [[Projects]] notes
- [[Literature]] notes often reference [[Authors]] and [[Themes]]

## Integration with Other Features

Backlinks work with:
