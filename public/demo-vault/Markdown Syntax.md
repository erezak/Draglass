# Markdown Syntax

Markdown is a lightweight markup language that makes it easy to format text without complex tools.

## Basic Formatting

### Headings
```markdown
# H1 Heading
## H2 Heading
### H3 Heading
```

### Emphasis
- *Italic* with `*asterisks*`
- **Bold** with `**double asterisks**`
- ***Bold and italic*** with `***triple asterisks***`

### Lists
Unordered lists use `-`, `*`, or `+`:
```markdown
- Item 1
- Item 2
  - Nested item
```

Ordered lists use numbers:
```markdown
1. First
2. Second
3. Third
```

## Links and Images

Regular links: `[Link text](https://example.com)`

Wikilinks (Draglass special): `[[Note Name]]` - see [[Wikilinks]]

Images: `![Alt text](image.png)`

## Code

Inline code uses `backticks`

Code blocks use triple backticks:
````markdown
```python
def hello():
    print("Hello!")
```
````

## Other Syntax

- Blockquotes: `> Quote text`
- Horizontal rules: `---` or `***`
- Tables (extended Markdown)
- Task lists: `- [ ] Todo item`

## Why Markdown?

Markdown is perfect for note-taking:
- Plain text, future-proof
- Easy to read and write
- Portable across tools
- Supported by [[Welcome to Draglass]] and many other apps
