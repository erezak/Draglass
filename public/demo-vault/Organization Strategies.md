# Organization Strategies

How you organize your vault affects how you think. Here are proven strategies for structuring your knowledge base.

## Folder Strategies

### PARA Method
- **Projects**: Active work with deadlines
- **Areas**: Ongoing responsibilities  
- **Resources**: Reference materials like [[Literature]] or [[Science]]
- **Archives**: Completed or inactive items

### Zettelkasten
- Use atomic notes (one idea per note)
- Connect via [[Wikilinks]]
- Let structure emerge naturally
- See [[Philosophy]] for the theoretical basis

### Topic-Based
- Group by subject: [[Technology]], [[History]], [[Philosophy]]
- Create index notes for each topic
- Use [[Folders and Structure]] effectively

## Linking Strategies

1. **Hub Notes**: Create index notes that link to related topics
2. **Daily Notes**: Time-based entry points
3. **MOCs**: Maps of Content for big topics
4. **Progressive Summarization**: Build up from highlights

## Naming Conventions

Good names make notes discoverable:
- Descriptive titles over cryptic codes
- Consistent capitalization
- Use full phrases for clarity

## Tags vs Folders vs Links

- **Folders**: Hierarchical organization
- **Tags**: Cross-cutting categories
- **[[Wikilinks]]**: Explicit relationships
- **[[Backlinks]]**: Emergent connections

Each has its place. Use what fits your workflow.

## Evolution Over Time

Your organization will evolve. That's good! As noted in [[Welcome to Draglass]], the goal is a system that works for you.
