# Daily Notes

Daily Notes are a popular note-taking pattern for capturing thoughts, tasks, and events as they happen.

## What Are Daily Notes?

A Daily Note is a note for a specific date, typically named with the date (e.g., "2024-01-15"). It serves as:
- A journal entry
- A task list for the day
- A log of events and thoughts
- An entry point into your vault

## Benefits

Daily Notes help you:
1. **Capture quickly**: One place for everything today
2. **Build a timeline**: Review your past days
3. **Create context**: Link events to projects and ideas
4. **Reduce friction**: Always know where to write

## Structure Ideas

A typical Daily Note might include:
```markdown
# 2024-01-15

## Tasks
- [ ] Review [[Project Alpha]]
- [x] Read chapter on [[Philosophy]]

## Notes
Today I learned about [[Wikilinks]]...

## Reflections
Interesting connection between [[Science]] and [[Art and Culture]]
```
