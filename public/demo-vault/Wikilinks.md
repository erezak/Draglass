# Wikilinks

Wikilinks are the core feature that makes Draglass powerful for building a knowledge base.

## What Are Wikilinks?

A wikilink is a reference to another note using double brackets:

```markdown
[[Another Note]]
```

When you click a wikilink, Draglass opens that note. If the note doesn't exist, it creates it!

## Why Wikilinks Matter

Wikilinks enable:

- **Bidirectional linking**: See [[Backlinks]] for connected notes
- **Knowledge graphs**: Visualize relationships in [[Graph View]]
- **Quick navigation**: Jump between related concepts
- **Emergent structure**: Your knowledge organizes itself naturally

## Creating Connections

As you write, think about connections:

- Link to related concepts: [[Philosophy]], [[Science]]
- Reference sources: [[Literature]] notes
- Connect project notes to [[Daily Notes]]
- Build topic clusters around themes

## Best Practices

1. **Link liberally**: Don't worry about over-linking
2. **Use full note names**: Be explicit rather than abbreviated
3. **Check your links**: Broken links appear differently
4. **Explore backlinks**: See what links to your current note
